# Section: Header / Navigation

## Purpose

Provide simple navigation and immediate brand recognition.

## Content

Brand:

- FollowBirds logo/name

Navigation links:

- How it works
- For guides
- Reports
- FAQ

Primary CTA:

- Become a Guide

Secondary link:

- Open Web App

## Behavior

- Header should remain simple and lightweight
- Links scroll to page sections if on same page
- CTA links can use TODO placeholders if final destination is not implemented

## Mobile

- Use a simple menu or stacked nav
- Keep CTA visible or easy to access

## Desktop

- Horizontal navigation
- Primary CTA on the right

## Avoid

- Login logic
- Complex dropdowns
- Heavy animation
