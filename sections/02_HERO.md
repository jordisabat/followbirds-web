# Section: Hero

## Purpose

A visitor should understand the product in 5 seconds.

## Main Message

FollowBirds helps guides run birdwatching tours and helps birdwatchers keep every observation forever.

## Suggested Copy

Headline:

> Birdwatching tours, live checklists and beautiful reports.

Alternative headline:

> FollowBirds helps guides run tours and birdwatchers keep every observation forever.

Subheadline:

> Create tours, share live sightings, build checklists and generate beautiful reports automatically.

## CTAs

Primary:

- Become a Guide

Secondary:

- Open Web App

Optional:

- Download App

## Visual

Use one of:

- Phone/app mockup
- Large birdwatching image
- Algarve nature image
- Bird + app UI composition

Use gradient overlay if text is placed over an image.

## Requirements

- Strong first impression
- Mobile-first
- Clear guide-first positioning
- Algarve/nature feeling

## Avoid

- Generic “bird database” positioning
- Worldwide positioning
- Too much text
