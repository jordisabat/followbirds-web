# Section: Example Tour Report

## Purpose

This is one of the strongest selling sections.

Reports are a key differentiator.

## Suggested Headline

> Every tour becomes a beautiful report.

## Suggested Copy

After each tour, FollowBirds turns observations, photos and route details into a shareable memory for every participant.

## Report Includes

- Tour information
- Guide
- Participants
- Timeline
- Species list
- Photos
- Notes
- Route map
- Weather later if available

## Outputs

- Web report
- PDF
- Shareable link
- Personal archive

## CTA

- See example report

## Visual

Use:

- Report mockup

- Photo gallery
- Route map preview

- Burying this section
